## 새 기능 — 자동완성 퀵 액션

자동완성 후보에서 컬럼을 고른 뒤 **→** 를 누르면 옆에 메뉴가 하나 더 열린다. 그 자리(구절)와 컬럼 타입에 맞는 꼴을 골라 한 번에 넣는다.

- 예: `where … and emp` 까지 치고 `EMPNO` 에서 → 를 누른다. 메뉴에서 `EMPNO = ` 를 고르면 들어가고 커서가 값 자리에 놓인다. 문자 컬럼이면 `ENAME = '│'` 처럼 따옴표 안에 놓인다.
- 메뉴에서는 ↑↓ 로 고르고 **Enter**(또는 Tab) 로 넣는다. 마우스로 눌러도 된다. **←**·Esc 를 누르면 후보 목록으로 돌아간다. 칸이 둘인 꼴(`BETWEEN … AND …`)은 Tab 으로 다음 칸에 간다.
- 퀵 액션이 있는 후보에는 오른쪽 끝에 `▸` 가 붙는다.
- 구절마다 권하는 꼴:
  - WHERE·AND·OR·ON·HAVING
    - 문자: `= ''` · `LIKE '%%'` · `IN ('')` · `<> ''`
    - 숫자: `=` · `IN ()` · `BETWEEN AND` · `<>`
    - 날짜: `TO_DATE('', 'YYYY-MM-DD')` 를 쓴 `=` · `>=` · `BETWEEN`, 그리고 `>= TRUNC(SYSDATE)`
    - 공통: `IS NULL` · `IS NOT NULL`
  - SET: 타입에 맞는 `= 값` 과 `= NULL`. 날짜는 `= SYSDATE` 도 권한다.
  - SELECT: `NVL` · `COUNT` · `MAX` · `AS`. 숫자는 `SUM`, 날짜는 `TO_CHAR` 도 권한다.
  - ORDER BY: `DESC` · `NULLS LAST` · `DESC NULLS LAST`
- `e.` 처럼 별칭 뒤에 칠 때는 커서 앞의 마지막 구절 키워드(WHERE·SET …)로 자리를 판단한다.
- 한글 입력 상태에서도 →·← 가 동작한다.
