## 새 기능 — 괄호 강조와 괄호 단위 선택

긴 서브쿼리나 겹친 함수 안에서 괄호가 어디서 열리고 닫히는지 찾기 쉽게 했다.

- **커서를 감싼 괄호를 강조한다.** 커서가 괄호 바로 옆이 아니라 괄호 안 어디에 있어도, 그 커서를 감싼 가장 안쪽 `(` 와 `)` 를 굵게·강조색으로 표시한다. 커서 바로 옆 괄호의 짝 표시도 테두리와 굵은 글씨로 강하게 했다. 짝이 없는 괄호는 경고색으로 보인다.
- 단축키:
  - **Ctrl+]** — 짝 괄호로 간다. 괄호 안에서 누르면 감싼 괄호의 끝 `)` 뒤로, 다시 누르면 `(` 앞으로 오간다.
  - **Ctrl+Shift+]** — 감싼 괄호의 안쪽을 고른다. 괄호와 그 바로 안의 공백·줄바꿈은 빼서, 서브쿼리면 `SELECT …` 만 고른다. 넓힌 뒤에 누르면 넓혀 온 길로 한 겹씩 돌아가고, 넓혀 온 길이 없으면 고른 괄호 안의 첫 괄호로 들어간다.
  - **Ctrl+Shift+[** — 한 겹 바깥 괄호의 안쪽으로 넓힌다. 누를 때마다 더 바깥으로 간다.
  - **Ctrl+Alt+] / Ctrl+Alt+[** — 같은 높이의 다음·이전 괄호 안쪽으로 옮긴다 (예: `WHERE a IN (…) AND b IN (…)` 의 두 괄호 사이).
- 괄호는 SQL 문법으로 찾아서 `')'` 같은 문자열이나 주석 안의 괄호는 세지 않는다. 한글 입력 상태에서도 단축키가 동작한다.

## 고친 것 — 붙여 넣기로 바꾼 탭에 ●(저장하지 않은 편집)가 뜨지 않던 것

탭 이름 앞의 ● 는 저장하지 않은 편집이 있다는 표시다. 글자를 칠 때만 켜지고, 붙여 넣기(Ctrl+V)·잘라내기·되돌리기·끌어 놓기·포맷으로 바꿨을 때는 켜지지 않았다. 그래서 탭 되살리기가 꺼져 있으면 붙여 넣기만 한 탭을 닫을 때 묻지 않고 내용이 사라질 수 있었다.

- 이제 내용이 바뀌면 방법에 상관없이 ● 를 켠다. 파일을 열거나 다시 읽어 내용을 바꾼 것만 편집으로 치지 않는다.

## 고친 것 — '값의 출처' 가 끊긴 곳을 알 수 있게

결과 열을 거슬러 가다 SELECT 목록에서 열을 찾지 못하면, 전에는 "SELECT 목록에서 QTY 을 찾지 못했습니다" 라고만 나왔다.

- 이제 그 쿼리의 SELECT 목록, 몇 번째 열을 찾았는지, 그 쿼리의 FROM·WHERE 를 함께 보인다. 예: `SELECT 목록 [ITEM, YM, CONV_QTY] 에서 QTY (3번째 열) 을 찾지 못했습니다`. 어느 블록에서 끊겼는지 알 수 있다.
- 계보 복사로 붙여 보내 주시면 그 경우를 바로 고칠 수 있다.
