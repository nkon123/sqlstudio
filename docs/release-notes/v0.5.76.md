## 결과 그리드 빠른 편집

**편집을 누른 뒤에는 셀을 고르고 바로 글자를 치면 고쳐진다 — 더블클릭하지 않아도 된다. 여러 칸을 골라 한 번에 넣거나 엑셀에서 붙여 넣을 수 있다.**

- **글자 치기** — 셀을 고르고 치면 그 글자로 고치기 시작한다 (한글도 첫 글자부터). 방향키를 누르면 넣고 옆 칸으로 간다. F2·Enter·더블클릭은 지금처럼 원래 값을 두고 고친다.
- **Enter · Shift+Enter** — 고친 값을 넣고 아래 칸 · 위 칸으로. 한 열을 위에서 아래로 차례로 고치기 쉽다.
- **Ctrl+Enter** — Shift·끌기·Ctrl+클릭으로 여러 칸을 고른 뒤 값을 치고 Ctrl+Enter 를 누르면 고른 칸 전부에 같은 값이 들어간다.
- **Ctrl+V** — 값 하나면 고른 칸 전부에, 엑셀에서 복사한 표면 같은 모양으로 붙는다. 고른 범위가 표 크기의 배수면 되풀이해 채우고, 끝을 넘는 부분은 잘라서 알린다.
- **Ctrl+D** — 열마다 맨 위 고른 칸 값을 아래로 채운다 (한 행만 골랐으면 바로 위 행 값을).
- **Backspace** — 고른 칸을 비운다 (NULL). 행 삭제 표시는 지금처럼 Delete.
- **Ctrl+Z** — 고친 것을 되돌린다. 붙여넣기·한 번에 넣기는 한 번에 되돌아간다.
- 여러 칸을 바꾸면 상태줄에 "N칸 바꿈 · M칸 건너뜀" 이 나온다. 고칠 수 없는 열, 지울 행, 다시 조회해야 하는 행은 건너뛴다. 바뀐 칸은 노란색이고, 적용을 눌러야 UPDATE 된다.
