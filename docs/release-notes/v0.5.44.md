## 흐름도에서 소스로 — 복사·소스 열기·행 번호

흐름도를 보다가 프로시저 내용을 확인하려면 이름을 옮겨 적어 따로 찾아야 했다. 이제 흐름도에서 바로 소스로 간다.

- **오른쪽 패널의 글을 골라 복사할 수 있다.** 0.5.41 에서 화면 밖 글 고르기를 막으면서 같이 막혔던 것이다. 이름 옆 ⧉ 단추로 이름만 바로 복사할 수도 있다.
- **'소스 열기' 단추.** 프로시저·트리거를 누르면 패널에 나온다. 소스를 새 탭에 열고, 패키지 안의 프로시저는 그 프로시저가 시작하는 줄로 간다. 테이블은 '구조 보기' 로 컬럼 목록을 연다.
- **행 번호를 누르면 그 줄로 간다.** '들어오는 것 / 나가는 것' 과 선 상세에 `SCOTT.EMP 쓰기 U · 25, 33행` 처럼 나오는 숫자가 링크다. 전에는 호출선에만 행 번호가 있었는데, 이제 테이블 읽기·쓰기에도 분석 결과에서 찾아 붙인다.
- **노드 오른쪽 클릭 메뉴.** 소스 열기 · 이름 복사 · 가운데로 · 숨기기. 더블클릭은 전처럼 '가운데로' 다.
- 소스는 지금 접속한 DB 에서 읽는다. 접속이 없을 때, 다른 곳에서 가져온(.sqla) 결과일 때, Pro*C·XML 단위(분석이 번역한 글이라 줄이 파일과 다르다)는 소스를 열지 않는다.
