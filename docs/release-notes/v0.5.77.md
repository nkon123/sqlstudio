## 오른쪽 보조 패널 — AI 옆에 테이블 상세

**오른쪽 영역이 AI 만이 아니라 테이블 상세(F4)·객체 상세를 탭으로 담는다. 와이드 모니터에서는 위에 테이블 상세, 아래에 AI 를 함께 본다.**

- 위쪽에 탭 줄 — `[AI] [EMP ×] [DEPT ×] …`. 같은 테이블을 다시 F4 하면 그 탭으로 간다. 탭의 × 나 가운데 클릭으로 닫는다.
- **위아래 나눠 보기** (기본 켜짐) — 상세가 있으면 위에 고른 상세, 아래에 AI. 경계선을 끌어 비율을 바꾸고, 더블클릭하면 반반.
- **여는 곳** — 창 폭이 1600px 이상이면 F4·상세 보기가 처음부터 오른쪽 탭으로 열리고, 좁으면 지금처럼 떠 있는 창. 오른쪽 패널의 `⋯` 에서 '늘 오른쪽'·'늘 떠 있는 창' 으로 바꿀 수 있다.
- 떠 있는 F4 창의 **⇥** 로 오른쪽에 붙이고, 붙인 창의 **⇱** 로 떼어 낸다. 같은 창을 옮기므로 고른 행·탭·거르기가 그대로다.
- 객체 목록의 **상세 보기** 도 넓은 화면이면 오른쪽 탭으로 — 아래쪽 결과 그리드를 가리지 않는다.
- 상세를 붙이면 오른쪽 폭이 좁을 때 560px 로 넓힌다. 오른쪽은 화면의 60% 까지 넓힐 수 있다.
- Ctrl+K 는 언제나 AI 입력칸으로 간다.

## 스크립트 탭 — DDL 정리, 인덱스·제약조건·권한

**F4 의 '스크립트' 탭(과 DDL 새 탭)에 테이블을 만드는 데 필요한 것이 모두 나온다.**

- **CREATE TABLE** 을 읽기 좋게 — 컬럼은 한 줄에 하나(이름 폭 맞춤), 제약조건의 USING INDEX·REFERENCES 와 끝의 저장 옵션(PCTFREE·STORAGE·TABLESPACE …)은 줄을 나눈다. 공백만 고치고 글자는 그대로다.
- **인덱스 생성문** — 일반·유일·BITMAP·함수 기반·DESC 인덱스. 기본 키·유일 제약조건이 만드는 인덱스는 CREATE TABLE 이 만드므로 빼서 두 번 나오지 않는다.
- **제약조건** — 기본 키·유일·외래 키·검사 제약은 CREATE TABLE 안에. DBMS_METADATA 를 쓸 수 없어 사전으로 만든 DDL 이면 기본 키 밖의 제약조건을 `ALTER TABLE … ADD CONSTRAINT` 로 붙인다.
- **권한** — 그 객체에 준 권한을 `GRANT SELECT, UPDATE ON SCOTT.EMP TO HR;` 처럼 받는 사람마다 한 줄로 (WITH GRANT OPTION · 열 권한 포함). 뷰·시퀀스 등도 권한이 붙는다.
- 패키지·프로시저 소스를 고치려고 열 때는 권한을 붙이지 않는다 (F5 로 GRANT 까지 다시 돌지 않게).
