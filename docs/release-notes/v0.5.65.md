## 왼쪽 패널 — 실행 이력도 왼쪽에

**메뉴의 '실행 이력' 을 누르면 테이블·프로젝트처럼 아래 영역이 실행 이력 목록이 된다.**

- 한 건을 두 줄로: ✓/✗ · 때 · 접속 · 실행 횟수 / 문장. 마우스를 올리면 전체 문장·걸린 시간·행 수·오류.
- 더블클릭·Enter: 편집기 커서에 넣기. 우클릭: 넣기 · 새 탭에서 열기 · 복사.
- 찾기 칸(낱말 여러 개), '이 접속만', 다시 읽기(↻). 이력을 보는 동안 SQL 을 실행하면 바로 다시 읽는다.
- 넓게 보려면 지금처럼 F8 의 이력 창.

## 왼쪽 메뉴 다듬기

- 메뉴에 **문서** 를 두었다 — 테이블·프로젝트·실행 이력을 보다가 한 번에 문서 목록으로 돌아온다. 지금 보는 것이 늘 강조된다.
- '열린 문서' 는 '문서' 로.
- 검색은 메뉴에서 빼고 '문서' 줄 오른쪽의 돋보기 아이콘으로. 누르면 찾기 칸이 열리고, 다시 누르거나 Esc 로 닫는다.
- 묶기는 글자 대신 아이콘으로 (마우스를 올리면 지금 묶기). 찾기 칸이 열려 있거나 묶어 보는 중이면 아이콘이 강조색.
- 접속으로 묶을 때 끊긴 문서도 같은 접속 묶음에 넣는다 (끊김은 문서 줄의 접속 이름에 보인다).
