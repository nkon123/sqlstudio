## 고친 것 — 한글 입력 상태에서 결과 그리드 방향키가 안 먹던 것

결과 그리드에서 셀을 고른 뒤 방향키를 눌러도 선택이 움직이지 않던 것 (껐다 켜도 그대로).

- 원인: Windows 의 한/영이 '한글' 이면 앱 화면이 방향키를 `ArrowDown` 이 아니라 `Process` 로 받는 경우가 있다. 그리드는 키 이름으로만 알아봐 키를 버렸다.
- 이제 키 이름이 `Process` 로 오면 실제로 눌린 물리 키로 알아본다 — 방향키·PgUp/PgDn·Home/End·Space. 컬럼 팝업(F4) 의 목록도 같은 그리드라 함께 고쳐졌다.
- 우클릭 메뉴의 방향키·Enter·Esc 도 같이 고쳤다.
