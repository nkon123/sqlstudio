## 접속 그룹 (#3)

**접속을 그룹으로 묶는다. 그룹은 두 단계까지 만들 수 있다(예: `ERP / 운영`).** 접속 → 접속 관리… 에서 관리한다.

- 접속 목록이 그룹 트리로 바뀐다. ▸/▾ 로 그룹을 접고 펴며, 접은 상태는 PC 마다 기억한다.
- ↑↓ 버튼으로 그룹과 접속의 순서를 바꾼다. 접속은 같은 그룹 안에서만 움직인다.
- 접속 편집 화면의 '그룹' 에서 접속이 속할 그룹을 고른다.
- **그룹 편집**: 이름 바꾸기, 상위 그룹 바꾸기(하위 그룹이 있는 그룹은 옮기지 않는다), 그룹 색, '이 그룹에 새 접속', '하위 그룹' 추가를 한다. 이름을 바꾸거나 옮기면 하위 그룹과 접속도 따라간다.
- **그룹 단위 일괄 설정**: 그룹 안 접속을 모두 운영 DB 로 표시하거나 해제하고, 모두 읽기 전용으로 바꾸거나 해제한다.
- **그룹 삭제**: '그룹만 삭제' 를 고르면 접속은 상위 그룹으로 옮긴다. '접속도 함께 삭제' 는 한 번 더 확인한다.
- 접속에 색이 없으면 그룹 색을 쓰고, 그룹에도 없으면 상위 그룹 색을 쓴다.
- 접속 메뉴는 그룹별 하위 메뉴로 보이고, 지금 접속이 든 그룹에 ● 를 붙인다. 툴바 접속 선택, 스키마 비교, 분석의 접속 선택 목록도 그룹별로 묶는다.
- config.toml 에는 `[[group]]` 항목과 접속별 `group = "ERP/운영"` 으로 저장한다. 예전 설정 파일은 그대로 읽힌다.

## EDIT 명령

**Toad 의 `EDIT 테이블 [WHERE …] [ORDER BY …]` 를 실행하면 그 테이블을 편집 그리드로 연다.**

- `EDIT emp WHERE deptno = 10` 은 `SELECT * FROM emp WHERE deptno = 10` 결과를 편집 상태로 연다(결과 그리드의 편집 버튼과 같다). `스키마.테이블` 과 따옴표 이름도 된다.
- 서버로 보내지 않는다. 편집 중이던 그리드에 적용하지 않은 변경이 있으면 버릴지 먼저 묻는다.

## 데이터 복사 — 커밋 간격

**도구 → 데이터 복사 에 '커밋 간격 ○행' 을 더했다. 정하면 그만큼 넣을 때마다 대상에서 커밋한다.** 수백만 건을 옮길 때 중간에 끊겨도 커밋한 데까지는 남고, 대상의 UNDO 가 모자라 실패하는 일을 줄인다.

- 비워 두면(기본값) 예전처럼 커밋하지 않고, 끝난 뒤 대상 탭에서 커밋하거나 롤백한다.
- 중간에 커밋하면 멈췄을 때 롤백으로 전부 되돌릴 수 없다. 복사 전 확인 창에 이를 적는다.
- 결과에 커밋한 행 수를 보인다. 커밋한 뒤 멈췄으면 방식을 MERGE 로 하거나 조건으로 남은 행만 골라 이어 옮기라고 안내한다.
- 복사의 시작·끝·멈춤을 로그(sqlstudio.log)에 남긴다. 멈추면 읽은·넣은·실패·커밋 행 수와 첫 오류 3개를 적는다.
