## MERGE 점검

**MERGE 문장 위에서 우클릭하면 '점검' 메뉴가 나온다 — 소스 데이터 때문에 실패하는 행을 찾는다.**

- **MERGE 중복 매칭 행 찾기 (ORA-30926)** — 대상 한 행에 ON 으로 소스 여러 행이 붙는 경우를 바로 조회해 결과 그리드에 보인다. 접속해 있을 때만.
- **MERGE 점검 쿼리 만들기 — 문장 아래에** — 점검 스크립트를 문장 바로 아래에 넣는다. ORA-30926(중복 매칭), ORA-00001(INSERT 갈래에서 같은 키가 두 번 들어감)을 찾는 쿼리가 들어가고, ON 에 쓴 열을 UPDATE SET 으로 고치면(ORA-38104) 주석으로 알린다.

## 서식 있는 복사

**결과 그리드에서 Ctrl+Alt+C 로 고른 셀을 서식 있는 표로 복사한다 — 엑셀·워드·메일에 붙이면 머리 색·테두리·줄무늬·열 폭이 따라간다.**

- 우클릭 메뉴에 **머리 포함 복사 (서식)** 이 생겼다 — 결과 그리드, 결과 비교, 용량, 컬럼 사용처, 컬럼 값 출처 창 모두.
- 붙일 곳이 흰 바탕인 경우가 많아 화면 테마와 관계없이 밝은 색으로 만든다. 숫자 열은 오른쪽 정렬, 나머지는 엑셀이 텍스트로 받아 앞의 0 이 남는다.
- 편집 중인 행은 표시가 따라간다 — 고친 셀은 노랑, 추가한 행은 초록, 지울 행은 취소선.

## 작은 고침

**F4 가 빈 줄 위 문장의 테이블을 보이던 것을 고쳤다.**

- `select * from tab` 아래 빈 줄을 두고 `sp_procedure` 를 적은 뒤 그 위에서 F4 를 누르면, `sp_procedure` 를 `tab` 의 별칭으로 읽어 TAB 의 컬럼을 보였다. 이제 빈 줄 너머는 다른 문장으로 보고 `sp_procedure` 를 찾는다. 바로 다음 줄에 적은 별칭(`from orders` ⏎ `o`)은 전과 같이 읽는다.

**다른 그룹에 같은 이름의 접속을 새로 만들면 기존 접속을 덮어쓰던 것을 고쳤다.**

- 접속 관리에서 새 접속을 저장할 때 같은 이름이 있는지 보지 않아, 그룹 A 의 `SCOTT` 이 있는데 그룹 B 에 `SCOTT` 을 새로 저장하면 A 의 것이 B 로 옮겨지며 덮어써졌다. 이제 "같은 이름의 접속이 있습니다" 로 막는다 — 접속 이름은 그룹과 관계없이 하나여야 한다.
