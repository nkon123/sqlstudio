## 화면 — Islands 디자인

**바탕 위에 패널을 둥근 섬으로 띄우고, 섬 사이는 선 대신 빈 간격으로 나눈다.**

- 버튼은 테두리 없는 모양이 기본이고, 채운 버튼은 실행·보내기 같은 주 동작만. 입력칸은 테두리 대신 한 단계 들어간 면.
- 편집기 탭은 알약 모양. 접속 색은 탭 제목 앞의 점으로 (색이 없는 접속은 점 없음).
- 결과·출력·실행계획·구조는 세그먼트, AI 빠른 동작은 칩, 내 질문은 말풍선, AI 입력은 둥근 상자.
- 경계선(좌우·위아래)은 평소엔 빈 간격이고, 마우스를 올리거나 끌 때만 선이 보인다.
- 운영 DB, 커밋 전 표시는 색과 의미 그대로.
- 섬 안에서 구역만 나누던 선은 지웠다. 그리드 셀·표 행처럼 읽는 데 필요한 선은 남겼다.
- 창이 좁으면(960px 이하) 명령 검색 단추는 돋보기만 보인다.

## 결과 영역 — SELECT 결과가 나오면 키우기

**SELECT 가 행을 돌려주면 결과 영역을 화면의 절반 남짓으로 키운다. 커서는 에디터에 그대로 있다.**

- 결과 영역이 이미 크면 그대로. 0행, DML·DDL, 오류는 바꾸지 않는다.
- 키운 비율은 기억하지 않는다 — 결과 영역의 ↕ 나 경계선 더블클릭으로 직접 정해 둔 비율로 돌아간다.
- 설정 → 편집기 → 결과 영역에서 끌 수 있다 (기본 켬).

## 다른 접속으로 데이터 복사 — 테이블이 없으면 만들기

**대상 줄의 '테이블이 없으면 만들기' 를 켜면, 대상에 테이블이 없을 때 원본 열 정의로 CREATE TABLE 한 뒤 옮긴다.**

- 원본의 열 이름·형식·NOT NULL·기본 키로 만든다. 기본값·인덱스·주석은 옮기지 않는다.
- 미리 보기에서 열을 줄이면 그 열로만 만든다 (기본 키 열을 빼면 기본 키도 뺀다).
- 미리 보기의 '실행할 SQL' 맨 앞에 CREATE TABLE 이 나온다.
- CREATE TABLE 은 바로 확정되어 롤백으로 지워지지 않는다. 대상 탭에 커밋 전 변경이 있으면 함께 커밋되므로, 먼저 커밋하거나 롤백하라고 알리고 멈춘다.
