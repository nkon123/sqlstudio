## PL/SQL 코드 탐색

**긴 패키지 본문에서 길을 잃지 않게 — 정의로 이동, 개요, 현재 위치, 뒤로/앞으로, 블록 접기.**

- **정의로 이동 (Ctrl+클릭 · F12)**: Ctrl 을 누르고 이름 위에 올리면 밑줄, 누르면 찾아 간다.
  - 같은 문서의 프로시저·함수·커서·타입이면 그 자리로 (본문 머리 ↔ 명세의 선언은 서로 오간다).
  - 없으면 DB 에서: 테이블은 구조 팝업, 프로시저·패키지는 소스 탭, `pkg.proc` 는 패키지 본문을 열고 그 프로시저로. F4 도 `pkg.proc` 를 이렇게 연다.
  - 이미 연 소스는 탭을 또 만들지 않고 그 탭으로.
  - Ctrl+클릭의 '커서 추가' 는 빈 곳·기호 위에서 그대로, 이름 위에 커서를 더하려면 Ctrl+Alt+클릭.
- **개요 (왼쪽 메뉴)**: 지금 문서의 패키지·프로시저·함수·커서·타입 목록. 커서가 있는 단위가 칠해지고, 누르면 그 자리로. 이름으로 거른다. PL/SQL 소스를 열면 왼쪽이 저절로 개요로.
- **구조 보기 (Ctrl+Shift+O)**: 같은 목록을 찾기 창으로 — 이름을 치고 Enter.
- **현재 위치 줄**: 편집기 위에 `패키지 › 프로시저 › FOR LOOP › IF`. 누르면 그 블록 처음으로. 일반 SELECT 문서에서는 숨는다.
- **커서 뒤로/앞으로 (Alt+← / Alt+→)**: 정의로 가거나 멀리(10줄 넘게) 옮기기 전 자리로.
- **블록 접기**: 줄 번호 옆 ▾, Ctrl+Shift+- / =. BEGIN…END · IF · LOOP · CASE · 프로시저 단위로, END 줄은 남긴다. Ctrl+Alt+- 는 패키지를 펼친 채 프로시저만 모두 접는다.
- 구조는 낱말로 짐작한다 (문법 검사 아님) — 3만 줄 패키지를 한 번 읽는 데 약 16ms.

## 주석이 아닌데 주석 색으로 보이던 것

**주석 안에 `/*` 가 한 번 더 있으면 그 뒤 코드가 끝까지 주석 색이었다.** 강조기가 주석을 겹쳐 세었다 — Oracle 처럼 처음 나오는 `*/` 에서 끝낸다. 예: `/*-- 변경이력 /* 2024 수정 */` 머리말, 막아 둔 힌트 `/*+ … */`.

## 왼쪽 메뉴

- **테이블 → 객체**: 이미 패키지·프로시저·시퀀스까지 종류를 골라 보던 목록이라 이름을 맞췄다.
- **새 문서**: 따로 한 줄이던 것을 '문서' 오른쪽 끝의 ＋ 로. 왼쪽을 접으면 편집기 위 탭 줄의 ＋.
- **개요** 추가 (위).

## 탭 여러 개 닫기

탭 우클릭에 **다른 탭 모두 닫기 · 위쪽(왼쪽) 탭 닫기 · 아래쪽(오른쪽) 탭 닫기 · 모두 닫기**. 보이는 순서 기준 — 왼쪽 목록이면 위·아래, 위 탭 줄이면 왼쪽·오른쪽. 저장 안 한 문서가 여럿이면 한 번에 묻는다 (남기기 / 모두 버리기). 실행 중·커밋 전 탭은 탭마다 묻는다.

## 가짜 DB 모드

- PL/SQL 소스 4개(PKG_ORDER · P_CLOSE_DAY · FN_EMP_GRADE · TRG_ORDERS_AUDIT)와 `#코드탐색` 시험 문서 — 코드 탐색을 접속 없이 시험한다.
- 이름에 `_` 가 있는 객체를 F4 로 못 찾던 것.
