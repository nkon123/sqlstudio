## SQL 정리 — SET 의 = 도 같은 칸에

**설정의 '연산자 맞추기'를 켜면 UPDATE 문과 MERGE 의 UPDATE 갈래에서 SET 대입의 `=` 를 같은 칸에 맞춘다.** 지금까지는 WHERE·ON 같은 조건 줄만 맞췄다.

```
UPDATE emp e
   SET e.sal            = 1
     , e.commission_pct = 2
 WHERE e.empno       = 7
   AND e.deptno_long = 1
```

- 서브쿼리처럼 여러 줄로 이어지는 항목은 맞추지 않고 그대로 둔다.
- 쉼표를 줄 끝에 두는 설정에서도 똑같이 맞춘다.
- 설정을 끄면(기본값) 예전처럼 맞추지 않는다.
