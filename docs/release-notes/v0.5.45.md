## 분석 화면 — 여는 중 표시, 글 복사

- **분석 화면을 열 때 무엇을 읽는지 보인다.** 전에는 여는 동안 오른쪽이 비어 있고 상태줄에 잠깐 글이 떴다 사라져, 읽는 중인지 멈춘 건지 알 수 없었다.
  - 툴바 아래 막대가 좌우로 오가며, 다 읽으면 멈춘다.
  - 결과가 아직 없으면 오른쪽에 단계 목록이 나온다. AI 모델 목록 → 저장된 분석 결과 목록 → 단위 목록 → 분석 결과(호출 관계·테이블 통합) 순서이고, 끝난 단계에는 ✓, 지금 단계는 파란색이다.
  - 상태줄에는 `분석 결과 (호출 관계·테이블 통합) 읽는 중… (4/4)` 처럼 나온다.
  - 결과를 보던 중에 다시 열면 결과는 그대로 두고 막대와 상태줄만 바뀐다.
- **그리드 밖의 글을 골라 복사할 수 있다.** 요약, 단위 상세(요약·시그니처·조각 코드), 호출 관계 상세, 테이블·사전 대조·확인할 것·품질 화면, 상태줄이다. 0.5.41 에서 앱 전체의 글 고르기를 막으면서 같이 막혔던 것이다. 단위 목록 같은 그리드는 전처럼 Ctrl+C 로 복사한다.
