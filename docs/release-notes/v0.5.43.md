## 고친 것 — MERGE 포맷에서 USING·ON·WHEN 이 한 칸 밀리던 것

MERGE 문을 포맷하면 USING·ON·WHEN 이 MERGE 보다 한 칸 오른쪽에 놓였다. SELECT 폭(여섯 칸)에 맞췄기 때문이다. 이제 MERGE 의 끝(다섯 칸)에 맞춘다.

```
MERGE INTO emp t
USING emp_new s
   ON (t.empno = s.empno)
 WHEN MATCHED THEN
      UPDATE
         SET t.sal = s.sal
```

- WHEN 아래의 UPDATE·INSERT 도 함께 한 칸 왼쪽으로 옮겨지고, 그 안의 줄 맞춤은 그대로다.
