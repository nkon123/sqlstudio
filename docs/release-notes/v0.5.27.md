## SQL 포맷 (Ctrl+Shift+F) — 오른쪽 맞춤·앞 쉼표 스타일 (0.5.27)

절 키워드를 SELECT 끝에 맞추고 쉼표를 앞에 두는, Toad·오렌지 사용자에게 익숙한 모양이 기본이 됐다. 포맷터를 직접 짜서 조인·CASE·서브쿼리까지 같은 규칙으로 맞춘다.

```sql
SELECT o.order_id
     , c.cust_nm
     , CASE WHEN o.status = 'C' THEN '취소'
            ELSE '정상'
       END st
  FROM orders o
  LEFT JOIN order_items i
    ON i.order_id = o.order_id
   AND i.use_yn = 'Y'
 WHERE o.order_dt >= TRUNC(SYSDATE) - 7
   AND EXISTS (SELECT 1
                 FROM payments p
                WHERE p.order_id = o.order_id)
 GROUP BY o.order_id
        , c.cust_nm
```

- **스타일 셋** — 오른쪽 맞춤·앞 쉼표(기본) / 간결(목록을 한 줄에 채움) / 왼쪽 정렬(전의 모양). **설정 > 편집기 > SQL 포맷** 에서 고르고 미리 보기로 바로 확인한다.
- **세부 설정** — 키워드 대소문자, 테이블·컬럼 이름 대소문자(기본 "그대로"), 쉼표 위치, AND·OR 위치.
- **예시로 맞추기** — 원하는 모양으로 정리한 SQL 을 붙여 넣으면 정렬 방식·쉼표·AND 위치·대소문자를 읽어 설정을 맞춘다.
- 다루는 문장: SELECT·WITH·INSERT·UPDATE·DELETE (UNION·인라인 뷰·스칼라 서브쿼리·계층 쿼리·중첩 CASE 포함). MERGE·DDL 은 왼쪽 정렬로 정리한다. `BETWEEN … AND` 의 AND, 함수·분석 함수 괄호 안, 문자열 속 `--`, q-quote, `(+)`, `@dblink`, 바인드는 건드리지 않는다.
- 결과가 공백·대소문자 말고 원본과 달라지면 적용하지 않는 검사는 그대로다. 앞 쉼표로 줄 끝 주석이 쉼표 앞으로 옮겨지는 것은 허용한다 (힌트 `/*+ */` 는 자리까지 같아야 한다).
- 업데이트하면 스타일은 기본(오른쪽 맞춤)으로 시작한다. 전의 모양을 원하면 "왼쪽 정렬" 을 고른다.

## 쓰는 동안 자동 포맷 (0.5.27)

**파일 ▾ > 자동 포맷** 에서 하나씩 켜고 끈다 (설정 > 편집기, 명령 검색에서도). 모두 기본은 꺼짐.

- **키워드 대소문자 바로 맞추기** — 낱말을 다 치면(띄어쓰기·줄바꿈·괄호·쉼표) 키워드만 설정의 대소문자로. 문자열·주석·따옴표 이름·`별칭.컬럼`·바인드, 컬럼 이름으로 흔한 낱말(YEAR·FIRST 등)은 그대로.
- **; 를 치면 그 문장 정리** — 줄 끝에서 `;` 를 치면 위의 빈 줄(또는 앞 `;`)부터 그 문장을.
- **SQL 을 붙여 넣으면 정리** — 줄 처음에 문장을 붙여 넣을 때. 들여 쓴 자리면 둘째 줄부터도 같이 들인다.
- **실행할 때 그 문장 정리** — Ctrl+Enter·F9 (선택해서 실행할 때는 그대로).
- SELECT·WITH·INSERT·UPDATE·DELETE·MERGE 로 시작하는 문장만 손댄다 — PL/SQL 안의 문장·DDL 은 그대로. 마음에 안 들면 Ctrl+Z.

## 상단 바 개편 · 명령 검색 (0.5.26)

버튼 27개가 한 줄로 늘어서 있던 툴바를 정리했다. 기능·단축키는 그대로이고 놓인 자리만 바뀌었다.

- **접속 단추** — 상태 점·프로필·계정@주소를 한데. 누르면 프로필 고르기·다시 접속·끊기·접속 관리. 운영 DB 면 빨간 테두리, 프로필 색은 왼쪽 띠로.
- **▶ 실행 · ▾** — 누르면 커서 위치 문장, ▾ 로 스크립트 전체·실행계획·디버그. 실행 중에는 그 자리가 **■ 중지 (경과 초)** 로 바뀐다.
- **커밋·롤백** — 커밋하지 않은 변경이 있을 때만 주황색 묶음으로 나타난다.
- **파일 ▾** (새 탭·열기·저장·인코딩 바꿔 저장·실행 이력·포맷), **도구 ▾** (분석·흐름도·디버그 / 스키마 비교·데이터 복사 / 용량·세션).
- **명령 검색 (Ctrl+Shift+P)** — 모든 명령과 "○○ 에 접속" 을 이름으로 찾아 실행한다. 단축키도 같이 보인다. 영문(commit, explain …)으로도 찾는다.
- 창이 좁으면(1100px 아래) 계정@주소와 단축키 표시를 숨긴다.

## 편집기 — 빈 줄로도 문장을 나눈다 (0.5.26)

커서 위치 문장 실행(Ctrl+Enter·F9)·실행계획이 `;`·`/` 줄뿐 아니라 **빈 줄**(공백만 있는 줄, CRLF 포함)에서도 문장을 끊는다. 세미콜론 없이 빈 줄로 나눠 쓴 문장들을 그대로 실행할 수 있다.

- 문자열·주석 안의 빈 줄, PL/SQL 블록 안의 빈 줄은 끊지 않는다.
- F5 스크립트 전체 실행은 그대로 `;`·`/` 로만 나눈다.

## AI — Oracle 문법 안내 카드 (0.5.26)

AI 에 물을 때 질문에 맞는 Oracle 문법 안내 카드를 몇 장 골라 함께 보낸다 (작은 로컬 모델이 Oracle 문법을 덜 틀리게).

- **카드 보기** — 설정 > AI > Oracle 문법 안내. 실제로 보내는 카드 전체, 어떤 낱말일 때 들어가는지, 기본·회사 규칙 구분을 본다.
- **회사 규칙으로 옮겨 고치기** — 기본 카드를 데이터 폴더의 `oracle-guides.md` 로 옮겨 편집기로 연다. 고쳐 저장하면 다음 질문부터 쓴다 (지우면 기본으로).
- **AI 로도 고르기** (자동 · 항상 · 끔, 기본 자동) — 낱말만으로 약하면 카드 주제 목록을 AI 에 먼저 보내 고르게 한 뒤 고른 카드만 질문과 함께 보낸다. "앞에서 다섯 개만" 처럼 낱말 목록에 없는 표현도 맞는 카드가 들어간다. 10초를 넘기거나 실패하면 낱말로 고른 것만 쓴다. AI 답 위 '참고 문법' 에 `(AI 선택)`·`(낱말+AI)` 로 표시.
- **카드 20장 추가** (36 → 56장) — WITH 절, 집합 연산, 숫자 형식(천 단위·반올림), 삭제·TRUNCATE, 날짜 목록 만들기(빈 날짜 0 채우기), 데이터 사전 조회, 트리거, 뷰·구체화 뷰, 인덱스, 예외 처리·오류 로그, CLOB, TIMESTAMP·시간대, JSON(12c+), 임시·복사 테이블, 한글(정렬·바이트), DB 링크, FLASHBACK(실수 되돌리기), 힌트·실행계획·통계, 바인드 오류, 객체·권한 오류.
- 기존 카드 보강 — 기본 규칙(SELECT 별칭은 같은 단계 WHERE 에서 못 씀, 23ai 문법 구분), ROWNUM 함정, LISTAGG ON OVERFLOW, ORA-00932·12704·01476.

## 데이터 폴더 지정 (0.5.25)

새 버전을 다른 폴더에 풀면 설정(접속 프로필)이 비어 보이던 문제 — 포터블은 설정을 실행 파일 옆 `data\` 에 둔다.

- **설정 > 정보 > 데이터 폴더** 에서 **폴더 지정…** — 실행 파일 바깥 폴더(예: `D:\SQLStudio-data`)를 정해 두면 새 버전에서도 같은 폴더만 다시 고르면 된다. 이전 SQLStudio 폴더를 고르면 그 안의 `data` 를 쓴다.
- 고른 폴더에 설정이 없으면 지금 설정·이력을 복사해 둔다. 포터블의 화면 설정은 다시 시작할 때 옮긴다.
- 포터블은 `portable.txt` 의, 설치판은 `%APPDATA%\sqlstudio\location.txt` 의 `data_dir=` 줄에 적힌다 (직접 넣어도 된다). 같은 폴더의 MCP 서버·분석 CLI 도 따른다.
- 저장한 비밀번호는 원래대로 Windows 자격 증명 관리자에 있어 폴더와 상관없다.

## 컬럼 팝업 (F4) (0.5.23 · 0.5.25)

- **Used By · Uses 탭** — 이 객체를 쓰는 곳(그 소스·뷰 정의에서 이름이 나오는 줄까지)과 이 객체가 쓰는 것. 직접 의존·동의어를 거친 것·FK 로 이어진 테이블. 행을 더블클릭하면 그 객체를 연다.
- **스크립트 탭** — 객체 DDL.
- **키보드로 고르고 넣기** — 방향키·Shift·Ctrl+방향키·Space 로 고르고, **Enter** 는 커서가 있던 절에 맞춰 넣는다 (SELECT·ORDER BY·GROUP BY 는 쉼표로, WHERE·ON·HAVING 은 조건으로). **Shift+Enter** 는 넣을 절 메뉴.
- **4방향 휠** — Ctrl+Shift(또는 Alt)를 누르고 있으면 ↑ SELECT · ↓ WHERE · ← ORDER BY · → GROUP BY, 떼면 그 절에 넣는다.
- **조건 값 틀** — WHERE 에 넣을 때 형식에 맞춘 빈 값: 문자는 `''`, DATE 는 `TO_DATE('', 'YYYY-MM-DD')`, TIMESTAMP 는 `TO_TIMESTAMP(…)`, 커서는 값 자리로.
- 결과 그리드도 방향키로 셀을 옮긴다.

## 고친 것

- **Used By 를 누르면 ORA-12704** 가 나던 것 (0.5.26) — 바인드 값(NVARCHAR2)을 UNION 의 결과 컬럼으로 고른 탓.
- **ROWID 열이 있는 결과에서 프로그램이 죽던 것** (0.5.22) — `a.ROWID RID` 같은 열이 있으면 행을 가져오기 전에 그 열만 문자로 바꿔 다시 연다.
- 컬럼 팝업에서 빈 WHERE·ORDER BY·GROUP BY 에 넣을 때 AND·쉼표가 잘못 붙던 것, 별칭 대신 테이블 이름에서 F4 로 열면 별칭 접두어가 빠지던 것 (0.5.24).
