## 밖에서 고친 파일을 바로 다시 읽기

**편집기에 연 파일을 외부 편집기나 AI 에이전트(opencode 등)가 고치면, 몇 초 안에 편집기에 그대로 반영된다.**

- 저장하지 않은 편집이 없으면 알아서 다시 읽는다 — 바뀐 곳만 바꿔 커서·스크롤은 제자리. **Ctrl+Z** 로 바뀌기 전으로 되돌릴 수 있다.
- 저장하지 않은 편집이 있으면 편집기 위에 알림 줄 — **[다시 읽기]** (디스크 내용으로) · **[비교]** (디스크 ↔ 편집기 나란히) · **[무시]**.
- 저장할 때 파일이 그사이 밖에서 바뀌었으면 덮어쓸지 묻는다 (전에는 말없이 덮어써 바깥 변경이 사라졌다).
- 1.5초마다, 그리고 창으로 돌아올 때 바로 확인한다. 파일이 없어지면 상태 줄에 알리고, 다시 생기면 읽는다.
