## 고친 것 — '값의 출처' 가 `SELECT 목록 [*] 에서 … 찾지 못했습니다` 로 끊기던 것

`FROM ( … ) a PIVOT ( … ) a` 처럼 쓴 쿼리에서 PIVOT 열의 출처를 보면, 집계 열까지는 찾고 그 다음에 `SELECT 목록 [*] 에서 QTY 을 찾지 못했습니다` 로 끝났다.

- 원인: 안쪽 어딘가의 `SELECT * FROM 테이블` 의 테이블을 자동완성 캐시가 몰라 `*` 를 열로 펼치지 못했다. 캐시를 읽은 뒤 만든 테이블, 동의어로 부르는 다른 스키마의 테이블, DB 링크 너머의 테이블 등이 그렇다. 이런 테이블은 열 목록을 DB 에서 받아 오는 대상에도 오르지 않았고, 받아 오기도 한 번뿐이었다.
- **열 목록을 몰라도 이름으로 잇는다.** `*` 가 가리키는 테이블이 하나면 같은 이름의 열이 그 테이블에 있다고 보고 `테이블.QTY` 까지 잇는다. 그 칸에는 "열 목록을 캐시에서 찾지 못해 이름으로 이었습니다 — 열이 실제로 있는지 확인하세요" 가 붙는다. 열 목록을 모르는 테이블이 둘 이상이면 어느 쪽인지 정하지 않는다.
- **스키마 없이 쓴 테이블도 열 목록을 받아 와 본다.** 접속한 사용자의 테이블로 보고 DB 에서 받아 온다. 받아 오면 타입·설명까지 정확히 나온다.
- **받아 온 뒤 더 안쪽에서 또 모르는 테이블이 나오면 3번까지 다시 받아 온다** (모두 합쳐 5초 안).
