## 결과 비교를 쉽게

**다시 실행하면 직전 결과와 바로 비교한다 — 미리 담거나 키 열을 고르지 않아도 된다.**

- **자동 비교**: 탭마다 직전 조회 결과 3개를 기억한다. 다시 실행하면 결과 탭 옆에 `직전과 ~5 +2 −1` (같으면 `직전과 같음`) — 누르면 비교가 열린다. 모양이 다른 결과(공통 열이 절반 미만)는 하지 않고, 사이에 다른 쿼리를 돌렸으면 그 앞의 같은 모양 결과와 (`이전과 …`).
- **키 열 자동**: 조회한 테이블의 기본 키로 행을 맞춘다. 결과에 없거나 겹치면 값이 겹치지 않는 앞쪽 열. 체크로 바꿀 수 있다.
- **다른 접속에서 실행해 비교**: `비교 ▾ → 다른 접속에서 실행해 비교 ▸ 프로필` — 같은 쿼리를 그 DB 에 읽기 전용 세션으로 돌려 바로 비교한다. 조회(SELECT)만, 탭의 기준 스키마도 그대로.
- **결과 자리에서**: 창을 띄우지 않고 그리드 자리에 — 바뀐 칸은 노랑(`이전 → 지금`), 추가 행은 초록, 없어진 행은 빨강 취소선. `✕ 결과로`(Esc)로 돌아가고 `창으로` 로 크게.
- **이전 결과 골라 비교**: `비교 ▾` 메뉴에 직전·이전 결과 3개. 다른 탭의 결과와는 예전처럼 '기준으로 담기' → '기준과 비교'.
- `비교 ▾` 단추를 결과 탭 바로 옆으로 — 결과 줄이 좁아도 보인다.
