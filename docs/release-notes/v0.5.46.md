## 영역 이동 — Ctrl+Shift+2

편집기에서 결과 그리드로 가려면 마우스로 그리드를 눌러야 했다. 이제 키보드로 편집기·결과 그리드·테이블 목록·AI 사이를 옮겨 다닌다.

- **Ctrl+Shift+2 를 누르면 가운데에 4방향 표시가 뜬다.** 방향키나 넘패드 8·2·4·6 으로 고르면 그곳으로 간다. 지금 있는 곳은 흐리게 나온다.
  - ↑ 편집기
  - ↓ 결과 그리드: 보던 셀이 있으면 거기로, 없으면 첫 셀로 간다.
  - ← 테이블 목록: 이름 필터 칸으로 간다.
  - → AI 입력칸
- **표시가 뜬 상태에서 한 번 더 누르면 직전 영역으로 돌아간다.** Ctrl+Shift+2 를 두 번 누르면 편집기와 그리드를 빠르게 오간다.
- 접혀 있는 왼쪽·오른쪽 영역은 펼치면서 간다. 분석 화면이 떠 있을 때 편집기나 그리드를 고르면 편집기 화면으로 돌아간다.
- Esc, 다른 키, 바깥 클릭으로 닫는다. 단축키 목록(F1)과 명령 검색(Ctrl+Shift+P)의 '영역 이동' 에도 있다.
- Ctrl+Shift 를 누르고 있는 동안 표시를 띄우는 방식은 쓰지 않았다. 편집기에서 단어 단위로 넓혀 고르는 Ctrl+Shift+←/→ 와 부딪히기 때문이다.
