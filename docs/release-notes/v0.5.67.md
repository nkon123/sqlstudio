## 문서 — README 최신화

**앱 기능은 0.5.66 과 같다. 설명서(README)만 지금 화면과 기능에 맞췄다.**

- 화면 구성: 툴바, 왼쪽 메뉴(문서 · 테이블 · 프로젝트 · 실행 이력, 아래 설정 · 도움말 · 접기), 문서 묶기(날짜 · 접속 · 태그), 결과 영역.
- 도구 메뉴: PL/SQL 분석, 데이터 흐름도, 행 추적, 디버그, 스키마 비교, 데이터 복사, 용량, 세션·락. 결과 그리드의 비교 · 내보내기 · 편집 · 값 추적.
- 단축키 추가 (명령 검색 Ctrl+Shift+P, 실행 이력 F8, AI 입력 Ctrl+K, 패널 접기 Ctrl+Shift+1/3, 단축키 목록 F1).
- AI 공급자에 ACP 에이전트, 하네스 설정.
- 안정성(하나만 실행, 오류 격리)과 속도(넓은 결과 스크롤, 실행 이력 찾기) 수치.
