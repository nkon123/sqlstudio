## 고침

- **다른 계정의 뷰·프로시저 스크립트가 안 보이던 것**:
  - 조회 권한만 있는 다른 계정의 객체에서 '스크립트' 를 열면 ORA-31603(객체를 찾을 수 없음)이 났다. DBMS_METADATA 는 다른 계정의 객체를 읽으려면 SELECT_CATALOG_ROLE 이 있어야 하는데, 이 오류만은 데이터 사전으로 만드는 경로로 가지 않았다.
  - 이제 31603 이어도 데이터 사전(ALL_VIEWS·ALL_SOURCE·테이블 정보)으로 DDL 을 만든다. 맨 위 주석이 그렇게 만든 것임을 알린다. 저장 옵션·권한은 빠진다.
  - 사전에도 없으면 처음 오류를 그대로 보인다.
