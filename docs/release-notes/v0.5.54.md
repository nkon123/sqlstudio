## 추적 화면 — 더 크게, 결과는 표로

**값 추적·행 추적 창이 거의 화면 전체로 뜨고, 찾은 결과를 카드 대신 표로 보인다.**

- 창이 화면의 98%×96% 로 뜬다. 전에는 대화상자 공통 한도(80%)에 걸려 생각보다 작았다. 왼쪽 소스 : 오른쪽 결과는 40 : 60.
- **넣는 문장 표**:
  - 칸: 상태 · 프로시저 · 줄 · 문장 · 거친 곳 · 다시 계산 값 · 지금 값 · 끊긴 곳 · 쿼리.
  - 행을 누르면 왼쪽 소스가 그 문장으로 가고, 그 행 아래에 자세한 계산(식·키·조건별 통과·조인 단계)이 펼쳐진다. 문장이 하나면 처음부터 펼쳐 둔다.
- **찾은 원본 행 표**:
  - 원본 테이블·열마다 하나. 키 열이 각각 칸이고, 값과 넣는 문장이 붙는다.
  - '↑ 어디서?' 로 거슬러 오른 단계는 표 아래에 이어 붙는다.
- 행 추적의 행을 넣는 문장·지우는 문장, 이 열을 넣지 않는 문장도 표로 보인다.
- 표마다 **표 복사** — 탭으로 나눈 글자라 엑셀에 그대로 붙여 넣는다.

## 결과 편집 — 행 추가

**편집 모드에서 새 행을 넣는다.**

- '행 추가' 단추나 **Insert** 키 → 끝에 새 행(번호 칸 `+`, 초록 바탕)이 붙고 첫 칸 입력이 열린다.
- '적용' 하면 `INSERT INTO 테이블 (값을 넣은 열) VALUES (…)` 를 보여 주고 확인 후 실행한다.
  - 값은 바인드로 넣는다.
  - 비운 열은 빼고 넣어 테이블의 DEFAULT·NULL 이 된다.
- 값을 하나도 넣지 않은 새 행이 있으면 적용하지 않고 알린다. 새 행에서 '행 삭제'·'되돌리기' 를 누르면 그 행이 빠진다.
- 넣은 행은 ROWID 를 모르므로, 다시 고치거나 지우려면 다시 조회한다.

## 고침

- **흐름도 창이 떴다 바로 닫히던 것**:
  - 증상: "창을 열 수 없습니다 … WebView2 Error … 호출된 개체가 해당 클라이언트로부터 연결이 끊겼습니다" (RPC_E_DISCONNECTED). 흐름도 창은 메인 창과 WebView 브라우저 프로세스를 함께 쓰는데, 그 프로세스와 연결이 끊겨 있으면 이렇게 실패했다.
  - 이제 한 번 더 열어 보고, 그래도 안 되면 따로 둔 WebView 데이터 폴더(`…-aux`)로 새 브라우저 프로세스에서 연다. 이때 화면 상태(테마 등)는 파일에서 채운다.
