## 접속 계정 하나에 세션 하나 (Toad 방식)

**같은 접속(프로필·계정·서버)으로 여는 탭은 서버 세션을 새로 만들지 않고 이미 열린 세션을 함께 쓴다.**

- 탭을 여러 개 열어도 `V$SESSION` 에는 그 계정 세션이 하나만 보인다. 두 번째 탭부터는 비밀번호도 다시 묻지 않는다.
- 결과 그리드의 "더 가져오기" 커서는 탭마다 따로 들고 있어, 한 탭에서 다시 실행해도 다른 탭의 열린 결과가 닫히지 않는다.
- 커밋·롤백·`ALTER SESSION`·기준 스키마는 그 계정의 모든 탭에 함께 적용된다. 한 탭이 오래 걸리는 쿼리를 돌리는 동안 같은 계정의 다른 탭 실행은 기다린다.
- 탭을 닫으면 그 탭의 결과만 닫고, 마지막 탭이 닫힐 때 서버 세션을 끊는다. 접속이 끊기거나 취소가 닿지 않아 세션을 버리면 같은 세션을 쓰던 탭들이 함께 다시 접속한다.

## 결과 그리드 — 끌어서 고를 때 스크롤

**셀을 끌어 선택하다 그리드 가장자리 밖으로 나가면 그 방향으로 스크롤하면서 선택이 이어진다.**

- 위·아래·왼쪽·오른쪽 모두. 멀리 나갈수록 빨리 스크롤된다.
- 전에는 그리드 밖으로 나가면 선택이 멈추고 스크롤도 되지 않았다.

## SELECT 목록 나누기 (Ctrl+Alt+L)

**커서가 있는 SELECT 하나만 나누고, 드래그해 골랐으면 걸린 SELECT 목록을 모두 나눈다.**

- 서브쿼리 안이면 그 서브쿼리, `UNION ALL` 이면 커서가 있는 갈래만 대상이 된다.

## MCP — 데이터 검증 하네스 (`run_check`)

**AI 가 쓴 검증용 SELECT 한 문장을 돌려 위반 행 수와 표본을 받는 `run_check` 툴을 추가했다 (기본 꺼짐).**

- 설정 `[mcp] allow_checks = true` 로 켜고 `check_max_rows` 로 표본 수를 정한다. 운영 프로필은 늘 거절하고, 호출마다 `mcp-checks.jsonl` 에 기록한다.
- 분석 결과를 읽는 `flow_reports` · `flow_report` · `data_lineage` · `subprogram_sql` · `column_writers` 툴도 더했다.
- 예시 작업 폴더는 `harness/validation` 에 있다.
