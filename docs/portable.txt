SQLStudio 포터블

이 파일이 sqlstudio.exe 옆에 있으면 포터블 모드로 실행됩니다.
설정·실행 이력·분석 결과·화면 설정을 이 폴더의 data\ 에 저장합니다 (PC 에 남기지 않음).
이 파일을 지우면 설치판처럼 %APPDATA%\sqlstudio 를 씁니다.

데이터 폴더 지정 (버전업 대비)
  새 버전을 다른 폴더에 풀면 data\ 가 비어 있어 설정이 없는 것처럼 보입니다.
  설정 > 정보 > 데이터 폴더 "폴더 지정…" 으로 실행 파일 바깥 폴더(예: D:\SQLStudio-data)를 고르면
  지금 설정·이력을 그리로 옮겨 쓰고, 새 버전에서도 같은 폴더만 다시 고르면 됩니다.
  (이전 SQLStudio 폴더를 고르면 그 안의 data\ 를 씁니다.)
  이 파일 끝에 직접 한 줄을 넣어도 됩니다 (상대 경로는 이 폴더 기준, 맨 앞 # 은 빼고):
  # data_dir=D:\SQLStudio-data
  버전업할 때 sqlstudio.exe 만 덮어쓰면 이 설정도 그대로 남습니다.

준비
  1. 압축을 쓰기 가능한 폴더에 풉니다 (Program Files 아래는 쓰기가 막혀 있어 안 됩니다).
  2. Oracle Instant Client 19 (64비트, Basic 또는 Basic Light) 를 이 폴더에 풀어 둡니다.
     예) SQLStudio\instantclient_19_25\oci.dll
     설정에 경로가 없으면 이 폴더를 자동으로 찾습니다. PATH 에 이미 있으면 넣지 않아도 됩니다.
     tnsnames.ora 는 instantclient_19_25\network\admin 에 두거나 설정에서 TNS 폴더를 지정합니다.
  3. sqlstudio.exe 를 실행합니다.

참고
  - WebView2 런타임이 필요합니다. Windows 10/11 에는 대부분 이미 있습니다.
    없으면 실행되지 않으니 설치판(setup.exe)을 쓰거나 WebView2 를 설치하세요.
  - 저장한 비밀번호는 파일이 아니라 Windows 자격 증명 관리자에 들어갑니다 (PC·사용자마다 따로).
  - 코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜰 수 있습니다: "추가 정보" → "실행".
  - MCP 서버·분석 CLI 가 필요하면 tools.zip 의 파일을 이 폴더에 함께 풉니다.
