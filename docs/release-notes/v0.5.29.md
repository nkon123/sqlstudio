## 분석 결과 가져오기 — 진행이 보이고, 멈춰도 이어서

큰 분석 파일(.sqla)을 가져올 때 "가져오는 중…" 만 떠서 되고 있는지 멈춘 건지 알 수 없던 것, 중간에 끊기면 처음부터 다시 해야 하던 것.

- **진행 표시** — 분석 화면 상태 줄에 단계·개수·경과 시간이 1초마다 바뀐다.
  `가져오는 중 · 파일 푸는 중 12,340/48,211 (25%) · 8초` → `단위 합치는 중 210/1,532` → `통합 결과(호출 관계·CRUD·흐름) 다시 만드는 중` → `마무리 중`. 개수를 모르는 단계도 초가 올라가 멈추지 않은 것이 보인다.
- **창이 묶이지 않는다** — 가져오기·합치기를 작업 스레드에서 돌린다 (전에는 앱의 메인 스레드에서 돌아 큰 파일이면 창이 '응답 없음' 처럼 보일 수 있었다).
- **가져오기 중지** — 진행 중에 상태 줄 옆에 나온다. 항목·단위 사이에서 멈추고 풀어 둔 것은 남긴다.
- **멈춰도 이어서** — 중지·앱 종료·PC 꺼짐·오류로 멈춘 가져오기는 분석 화면 위에 **중단된 가져오기** 로 보인다.
  - **이어서**: 다 푼 항목은 건너뛰고, 이미 합친 단위는 그대로 두고 남은 것만. 통합 결과는 꼭 다시 만든다.
  - **버리기**: 풀어 둔 것을 지운다 (이미 합친 단위는 남는다).
  - 원본 파일이 바뀌었거나 없어졌으면(크기·수정 시각) 이어서 할 수 없다고 알린다.
- **접속의 결과에 합치기** 도 진행이 보이고 중지할 수 있다 (다시 하면 남은 단위만 합친다).
- 이 버전 전에 멈춘 가져오기는 기록이 없어 이어서 할 수 없다 — 다시 가져온다.
