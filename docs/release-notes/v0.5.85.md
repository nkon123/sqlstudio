## 포맷 — 괄호 바로 뒤에 주석이 있는 서브쿼리

**`FROM (/* 메모 */ SELECT …` 처럼 여는 괄호 바로 뒤에 주석이 있어도 서브쿼리로 알아보고 `SELECT`·`FROM`·`UNION ALL` 을 맞춘다.**

- 전에는 주석 뒤의 서브쿼리를 한 줄로 이어 붙였다 (`SELECT EMPNO, ENAME … FROM EMP UNION ALL SELECT …`).
- 여러 줄 블록 주석(주석 처리해 둔 SQL 등)은 옮겨 간 만큼 안쪽 줄도 함께 옮긴다 — 주석 안의 SQL 이 어긋나지 않는다.

## 포맷 — UNION ALL 사이사이의 주석

**주석이 여럿 섞여도 오른쪽 맞춤이 왼쪽 정렬로 바뀌거나, 다시 포맷할 때마다 모양이 달라지지 않는다.**

- `UNION -- 메모` 다음 줄에 `ALL /* 주석 */` 이 오면 뒤의 주석을 다음 `SELECT` 앞에 둔다. 전에는 `--` 주석 뒤에 이어 붙을 뻔해 왼쪽 정렬로 넘어갔다.
- 쉼표·`AND` 바로 뒤에 주석이 있어도 쉼표·`AND` 만 한 줄에 남지 않는다.
- `SELECT`·`FROM`·`SET` 바로 뒤의 제 줄 주석은 키워드 줄 앞에 둔다 — 키워드만 한 줄에 남지 않는다.
- `INSERT -- 메모 INTO`, `ORDER -- 메모 BY` 처럼 키워드 사이에 주석이 있어도 오른쪽 맞춤을 유지한다.
