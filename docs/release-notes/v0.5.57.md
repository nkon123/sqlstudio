## ACP 에이전트 (opencode 등)

**AI 패널에서 opencode 같은 ACP(Agent Client Protocol) 에이전트를 골라 질문한다.**

- AI 패널 제공자 목록에 **ACP 에이전트** 묶음이 생긴다. opencode 가 PATH 에 있으면 설정 없이도 보인다.
- 에이전트를 처음 고르면 질문이 외부로 나간다는 동의를 한 번 묻는다. 배지는 '외부 전송'.
- 답은 흘려 받으며 보인다. 에이전트가 쓰는 도구, 계획, 사용량도 함께 보인다.
- 에이전트가 권한을 물으면 창을 띄워 고르게 한다. 멈춤은 에이전트에 취소를 보낸다.
- 모델과 모드는 패널 위 선택 칸에서 바꾼다. 새 대화는 처음 모드(기본 `plan`)로 시작한다.
- MCP 를 켜 두고 MCP 허용 접속이 있으면, 에이전트에 sqlstudio-mcp(읽기 전용 사전 도구)를 넘긴다.
- 앱을 닫으면 에이전트 프로세스도 끝낸다.
- 주의: opencode 는 `plan` 모드에서도 셸 명령을 묻지 않고 실행할 수 있다. 막으려면 opencode 설정에서 bash 권한을 `ask` 로 둔다.

## 설정 → AI → ACP 에이전트

- 에이전트를 추가·수정·삭제한다: 이름, 실행 파일, 인자, 작업 폴더, 처음 모드, MCP 넘김.
- **연결 테스트** 로 에이전트를 띄워 응답하는지 본다.
- `config.toml` 에는 `[[acp]]` 로 저장된다. 실행 파일이나 인자를 바꾸면 외부 전송 동의를 다시 묻는다.
