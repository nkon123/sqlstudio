## MERGE 포맷 — 주석이 있으면 깨지던 것

**`WHEN MATCHED THEN`, `WHEN NOT MATCHED THEN`, 갈래 안의 `UPDATE`·`DELETE` 바로 뒤나 그 사이에 `--` 주석이 있으면 MERGE 포맷이 깨지던 것을 고쳤다.**

- 증상: 오른쪽 맞춤 포맷이 MERGE 를 읽지 못해 왼쪽 정렬 포맷으로 넘어갔다. 그래서 `USING (` 가 대상 테이블 줄에 붙고, `DELETE` 가 앞 줄 끝에 붙고, 들여쓰기가 들쭉날쭉해졌다.
- 이제 키워드와 같은 줄에 있던 주석은 그 줄 끝에 그대로 둔다(`WHEN MATCHED THEN -- 메모`). 제 줄에 따로 있던 주석은 다음 키워드와 같은 칸에 맞춘다.
- MERGE, SELECT, UPDATE, DELETE, INSERT, WITH, UNION, CASE 에서 줄마다 주석을 넣은 126가지 경우로 확인했다.
