## 하나만 실행

**SQLStudio 를 이미 띄워 두었는데 또 실행하면, 떠 있는 창을 앞으로 가져오고 새로 띄우지 않는다.**

- 둘을 띄우면 같은 탭 자동 저장(tabs.json)을 나중에 닫은 쪽이 덮어써, 먼저 닫은 창에서 저장하지 않고 쓰던 SQL 이 다음에 켤 때 되살아나지 않았다.
- 설치판과 포터블판도 같은 앱으로 본다 — 함께 띄울 수 없다.
- 데이터 폴더를 바꾼 뒤의 재시작은 그대로.

## 왼쪽 패널 — 아래에 설정·도움말·접기, 접으면 아이콘 줄

- 설정(⚙)·도움말(?)을 위 툴바에서 왼쪽 패널 맨 아래로 옮겼다. 위 툴바에는 접속·실행·커밋 같은 일하는 단추만.
- 그 아래 **접기**. 접으면 패널이 사라지지 않고 아이콘 줄(새 문서 · 문서 · 테이블 · 프로젝트 · 실행 이력 / 설정 · 도움말 · 펼치기)로 남는다.
- 아이콘 줄에서 문서·테이블·프로젝트·실행 이력을 누르면 펼치며 그 화면으로. Ctrl+Shift+1 도 그대로.

## 빨라진 것

- **결과 그리드**: 화면에 보이는 열만 그린다. 열 150개 결과에서 스크롤 한 번이 약 50ms → 12ms.
- **열 너비 계산**: 열이 많으면 재는 칸을 줄이고, 지금 폭을 못 넘는 짧은 값은 재지 않는다.
- **숫자 열 정렬**: 10만 행 83ms → 13ms (정렬 전에 한 번만 숫자로 바꾼다).
- **실행 이력 찾기**: 이력이 많을 때(24만 건) 한 번에 150~250ms → 3~38ms. 200개를 채우면 멈추고, 맞지 않는 줄은 풀지 않는다.
- **탭 자동 저장**: 치는 동안은 쓰지 않고 손을 멈추고 2초 뒤에 (계속 쳐도 30초에 한 번은).
- **문서 목록 미리 보기**: 큰 문서도 앞줄만 본다.

## 안정성

- 한 작업에서 예상 못 한 오류(패닉)가 나도 다른 기능(접속·실행·자동완성 등)이 줄줄이 멈추지 않게 — 공유 상태 잠금 20곳을 오류에 견디는 방식으로.
- 설정·탭·화면 상태를 저장할 때 임시 파일 이름에 프로세스 번호를 붙였다 (둘이 같은 폴더에 쓸 때 '저장 실패 (os error 2)' 가 나던 것).
- 화면 코드에서 잡지 않은 오류도 로그에 남긴다 ("화면 오류 (…)").
