## 분석 — ACP 에이전트의 모델 고르기

**도구 → 분석에서 ACP 에이전트(opencode)를 고르면 공급자 옆에 모델 칸이 나온다 — 그 분석에 쓸 모델을 고른다.**

- 목록은 에이전트가 내놓는 모델. 에이전트 설정의 모델에는 '(설정)' 이 붙는다.
- 고른 모델은 이 분석에만 쓴다 — 에이전트 설정의 기본 모델(AI 패널)은 바꾸지 않는다. 고른 것은 이 PC 에 기억한다.
- 모델을 바꾸면 조각 줄 수를 그 모델의 컨텍스트 크기로 다시 정한다 (직접 바꾼 줄 수는 그대로).
- 분석 결과는 모델별로 저장된다 — 모델을 바꾸면 조각을 그 모델로 다시 묻는다.
- 공급자 목록의 '· 에이전트 기본 모델' 글은 뺐다 (모델 칸으로).
