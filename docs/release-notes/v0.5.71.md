## 더 빠른 시작

**탭이 많아도 빨리 뜨고, 처음 불러오는 화면 코드가 36% 줄었다.**

- 지난 탭을 되살릴 때 탭마다 목록을 다시 그리고 포커스를 옮기지 않는다 — 끝에 한 번. 탭 33개를 0.1초 남짓에 (전에는 11개에 0.1~0.24초). 파일로 저장된 탭은 한꺼번에 읽는다 (네트워크 드라이브에서 덜 기다린다).
- 설정 · PL/SQL 분석 · 값 추적 화면은 처음 쓸 때 불러온다. SQL 포맷터는 첫 화면이 뜬 뒤 쉬는 틈에 — main.js 1,205KB → 770KB.

## 탭 자동 저장은 바뀐 탭만

- 탭 내용을 데이터 폴더의 `tabs/<탭>.sql` 에 따로 두고, 몇 초마다 저장할 때 바뀐 탭만 다시 쓴다 (큰 소스를 여러 개 열어 둬도 가볍게). 닫은 탭의 파일은 지운다.
- 예전 형식(`tabs.json` 하나)은 처음 켤 때 읽어 새 형식으로 옮긴다. **새 형식으로 저장한 뒤 0.5.70 이하로 되돌리면 지난 탭이 보이지 않는다** (내용은 `tabs` 폴더에 남는다).

## 성능 기록

- 0.3초 넘게 걸린 실행 · 더 가져오기 · 구조 보기를 로그(`sqlstudio.log`)에 `성능 …` 으로 남긴다 — 걸린 시간, 행 × 열, 받은 글자 크기.
- 화면 쪽이 느리면 `성능 화면: … 서버 · 받기 · 그리기` 로 나눠서.
- 자동완성 캐시를 읽을 때 단계별(객체 · 컬럼 · 동의어 · 키) 시간.
