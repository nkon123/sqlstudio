## 편집 탭 자동 저장·복원

프로그램이 죽거나 PC 가 꺼져도 쓰던 SQL 이 남는다.

- 탭 내용·파일 경로·인코딩·커서·저장하지 않은 표시(●)를 몇 초마다 데이터 폴더의 `tabs.json` 에 남기고, **다음에 켜면 탭을 되살린다** (마지막에 보던 탭으로).
- 파일로 저장한 탭은 디스크에서 다시 읽는다 (밖에서 고쳤을 수 있다). 파일이 없어졌으면 남긴 내용을 '저장 안 함' 으로.
- **접속은 되살리지 않는다** (운영 DB 일 수 있다) — 그 탭의 프로필만 골라 둔다.
- 되살리는 동안은 닫을 때 "저장하지 않은 편집" 을 묻지 않는다 (커밋하지 않은 트랜잭션은 그대로 묻는다). **설정 > 편집기 > 탭** 에서 끈다.

## 안정성

- **한 작업의 오류가 앱 전체를 멈추게 하던 것** — 백엔드의 공유 잠금은 잠근 작업이 비정상 종료하면 '오염' 되어, 그 뒤 같은 잠금을 쓰는 모든 명령이 연달아 실패했다. 오염돼도 계속 쓰게 바꿨다 (오류는 로그에 남는다).
- **BFILE 열이 있으면 조회가 멈추던 것** — 드라이버가 값을 글자로 바꾸려고 서버의 파일을 열다 응답 없이 멈췄다 (디렉터리·파일이 없을 때). BFILE 이 든 테이블을 `SELECT *` 하면 그 탭의 세션이 묶였다. 이제 파일을 열지 않고 `(BFILE)` 로 보인다.
- **IOT(인덱스 조직 테이블)의 ROWID 조회가 ORA-01410 으로 실패하던 것** — 논리 ROWID 를 `ROWIDTOCHAR` 로 바꾸려 했다. `CAST(… AS VARCHAR2)` 로 바꿔 일반·논리 ROWID 모두 보인다.
- **XMLTYPE·객체 형식 열** — ROWID 처럼 행을 가져오기 전에 SQL 로 바꿔 둔다. XMLTYPE 은 글자(XMLSERIALIZE)로, SDO_GEOMETRY·사용자 정의 객체·VARRAY·중첩 테이블·ANYDATA 는 `(MDSYS.SDO_GEOMETRY)` 처럼 형식 이름으로 (NULL 은 NULL).
- 형식마다 실제 Oracle(11g XE)에서 조회해 보는 통합 테스트를 넣었다 — 숫자·문자·날짜·TIMESTAMP(시간대 포함)·INTERVAL·RAW·CLOB·NCLOB·BLOB·BFILE·XMLTYPE·객체·VARRAY·중첩 테이블·UROWID·LONG·LONG RAW·IOT ROWID·CURSOR 식·ANYDATA·SDO_GEOMETRY. 위 두 버그는 이 테스트가 찾았다.

## 설정 파일의 상대 경로

- `config.toml` 의 `[oracle] client_lib_dir`(Instant Client)·`tns_admin`(tnsnames.ora 폴더)에 **상대 경로**를 쓸 수 있다 — `sqlstudio.exe` 가 있는 폴더 기준. 포터블이면 `client_lib_dir = 'instantclient_19_25'` 처럼 써 두면 폴더째 옮겨도 그대로 된다.
- 설정 화면에서 프로그램 폴더 안의 TNS 폴더를 고르면 상대 경로로 저장한다. 앱·MCP 서버·분석 CLI 가 같은 규칙으로 푼다.

## SQL 포맷

- **실행할 때 정리(자동 포맷)·Ctrl+Shift+F·`;` 정리가 첫 줄 들여쓰기를 남기던 것** — 정리한 SQL 끝에서 Enter 로 다음 SQL 을 쓰면 들여쓰기가 이어져, 첫 줄만 밀린 채로 정리됐다. 문장 앞에 공백만 있으면 줄 처음부터 정리한다.
- 공백만 있는 줄에서 Enter 를 치면 그 줄에 공백을 남기지 않는다 (SQL 사이 빈 줄에 보이지 않는 공백이 쌓이던 것).
