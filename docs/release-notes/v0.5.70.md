## 기준 스키마

**접속은 그대로 두고, 계정을 적지 않은 테이블을 어느 스키마에서 찾을지 상단에서 고른다.**

- 툴바의 접속 단추 옆 `스키마 SCOTT ▾` — 누르면 접속 계정과 다른 스키마 목록 (이름으로 찾기). 고르면 `ALTER SESSION SET CURRENT_SCHEMA` 를 걸어 `select * from tab` 이 `A.tab` 으로 실행된다. `b.tab` 처럼 계정을 적은 것은 그대로, 기본은 접속 계정.
- 다른 스키마를 고르면 단추가 강조색으로. 권한은 바꾸지 않는다 — 그 스키마 객체를 읽을 권한이 있어야 한다.
- 같은 기준으로: 자동완성(`from` 뒤 후보 · 별칭 뒤 컬럼), F4 · Ctrl+클릭 · 구조 보기 · 소스 열기 · 영향도(그 스키마에서 먼저, 없으면 동의어·접속 계정), 결과 건수, 왼쪽 객체 목록(더블클릭하면 계정 없이 이름만).
- 편집기에서 `ALTER SESSION SET CURRENT_SCHEMA = …` 를 직접 실행해도 상단 표시가 따라간다.
- 탭마다 기억한다 — 같은 프로필로 다시 접속하면 다시 걸고, 다음에 켤 때도 남는다. 다른 프로필로 접속하면 접속 계정으로.
