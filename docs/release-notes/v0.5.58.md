## ACP 에이전트 — 고른 모델을 기억

**AI 패널에서 고른 에이전트 모델이 설정에 남아, 새 대화와 다음 실행에서도 그 모델로 시작한다.**

- 패널 위 모델 칸에서 고르면 그 에이전트 설정(`[[acp]]` 의 `model`)에 저장된다.
- 새 대화를 열 때 저장된 모델로 바꿔 둔다. 그 모델을 에이전트가 더 내놓지 않으면 에이전트 기본값으로 연다.
- **설정 → AI → ACP 에이전트** 에 **모델** 칸이 생겼다. 비우면 에이전트 기본값.
- 모드는 저장하지 않는다 — `build` 가 굳으면 편집 도구가 늘 열린다. 처음 모드는 설정의 **처음 모드** 로 정한다.

## ACP 에이전트 — 빠른 시작

**느린 PC 에서 opencode 를 기다리는 시간을 줄였다.**

- opencode 를 띄울 때 `--pure` 를 늘 붙인다 (외부 플러그인을 읽지 않아 시작이 크게 빠르다). 예전에 `acp` 만으로 저장한 설정에도 붙는다.
- 지난번에 AI 패널에서 에이전트를 골라 두었으면 앱을 열 때 미리 띄운다. 첫 질문에서 기다리지 않는다.
- 시작하는 동안 상태줄에 걸린 초를 보인다 (`opencode 시작 중… 23초`).
- 시작 시간 제한을 60초에서 180초로, 세션 열기·설정 바꾸기는 120초로 늘렸다.
