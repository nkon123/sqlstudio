## SELECT 목록을 몇 줄로 — Ctrl+Alt+L

컬럼이 많은 SELECT 목록을 원하는 줄 수로 나누어 표처럼 칸을 맞춘다. 기본 포맷(한 줄에 하나)은 그대로 두고, 고른 목록만 다시 배치한다.

- **고른 영역(없으면 커서가 있는 문장)의 SELECT 목록을 나눈다.** 몇 줄로 할지 묻는 창에서 줄 수를 바꾸면 바로 미리 보기가 바뀐다. 마지막에 쓴 줄 수는 기억한다.
- 쉼표를 앞에 둘지 뒤에 둘지는 포맷 설정을 따른다. 한글은 두 칸으로 센다. 괄호나 문자열 안의 쉼표에서는 나누지 않는다.
- 편집기 오른쪽 클릭 메뉴의 'SELECT 목록을 몇 줄로…', 파일 메뉴, 명령 팔레트에서도 쓸 수 있다.
- **이렇게 맞춘 문장은 자동 포맷이 다시 풀지 않는다.** 실행할 때 정리와 `;` 칠 때 정리 모두 그 문장을 건너뛴다. Ctrl+Shift+F 로 직접 포맷하면 다시 포맷하고 보호도 풀린다.
- 보호는 문장 전체에 걸리므로, 먼저 Ctrl+Shift+F 로 문장을 정리한 뒤 목록을 나누면 좋다.

## SQL 포맷 — 조건의 연산자 맞추기, UNION 위치

- **조건의 연산자를 같은 칸에 맞출 수 있다.** 설정 > 편집기 > SQL 포맷의 '조건의 연산자 맞추기' 이고 기본은 꺼져 있다.
  - WHERE·ON·HAVING·CONNECT BY·START WITH 에서 AND·OR 로 이어진 줄의 `=` `<>` `!=` `>=` `<=` `>` `<` `LIKE` `NOT LIKE` `IN` `NOT IN` `BETWEEN` `IS` 를 같은 칸에 놓는다.
  - 절마다 따로 맞춘다. 서브쿼리처럼 여러 줄인 조건은 빼고, 문자열 안은 보지 않는다.
  - '예시로 맞추기' 에 연산자를 맞춘 SQL 을 주면 이 설정도 켠다.
- **UNION ALL·MINUS 를 절 키워드처럼 오른쪽에 맞춘다.** 위 조건의 `AND` 의 D 와 `UNION` 의 N 이 같은 칸에 온다.

## 고친 것 — 한글 입력 상태에서 Ctrl+Alt 단축키가 먹지 않던 것

Ctrl+Alt+L(목록 나누기)과 Ctrl+Alt+U(소문자)가 한글 입력 상태에서는 아무 일도 하지 않았다. 편집기가 Windows 의 Ctrl+Alt 를 AltGr 로 보고, 'ㅣ' 를 L 키로 바꿔 찾지 않았기 때문이다. 이제 입력 상태와 상관없이 눌린 키 자리로 받는다.
