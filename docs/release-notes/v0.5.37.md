## 고친 것 — 네트워크 드라이브의 포터블에서 시작이 6초 걸리던 것

포터블을 네트워크 드라이브에 두고 쓰면 시작 로그(`시작(화면 앞)`)의 `문서 받음` 이 5~6초였다. 화면(WebView)의 데이터 폴더가 실행 파일 옆 `data\webview`, 곧 네트워크 드라이브에 있었기 때문이다. Microsoft 도 WebView2 데이터 폴더를 네트워크 경로에 두는 것은 지원하지 않는다.

- **포터블의 WebView 데이터 폴더를 로컬 PC 로 옮긴다.** 위치는 `%LOCALAPPDATA%\SQLStudio\webview-…` 다. 포터블 폴더가 여럿이면 폴더마다 따로 둔다.
- **화면 상태는 데이터 폴더의 `ui-state.json` 에 함께 적는다.** 테마·에디터 색·바인드 이력·화면 배치·최근 파일·마지막 프로필 같은 것이다. 창을 열 때 그 파일이 더 새것이면 그 내용으로 시작한다. 그래서 리모트 환경처럼 쓸 때마다 PC 가 바뀌어도 상태가 그대로 따라온다.
- 이미 쓰던 포터블은 이 버전을 처음 켤 때 예전 `data\webview` 의 값을 `ui-state.json` 으로 옮겨 적는다. 다음 실행부터 로컬 폴더를 쓴다. 예전 `data\webview` 폴더는 남겨 두므로 지워도 된다.
- 설정(`config.toml`)·로그·열린 탭·분석 결과는 지금처럼 데이터 폴더에 있다.
- 로그에 `WebView 데이터 폴더 …` 줄을 남겨, 어느 폴더를 쓰는지 알 수 있다.
